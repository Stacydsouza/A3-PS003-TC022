NoCivicSense

Federated Traffic-Flow Prediction with Communication-Cost Evaluation

Hackathon: AIORI-3
Problem Statement: PS-003
Domain: Artificial Intelligence, Machine Learning, Federated Learning, and Smart Cities

Project Overview

NoCivicSense explores the use of federated learning for traffic-flow prediction when traffic data is distributed across multiple locations or organizations. Instead of centralizing raw traffic data, simulated clients train a machine learning model locally and share model updates with a central aggregation server.

The proposed approach combines a Gated Recurrent Unit (GRU) for time-series forecasting with Federated Averaging (FedAvg) to aggregate local model updates into a global model.

Objectives

Predict future traffic flow using historical traffic data.

Explore collaborative model training without transferring raw client data.

Compare centralized and federated learning approaches.

Evaluate IID and non-IID client data distributions.

Measure prediction performance using MAE and RMSE.

Analyse communication overhead and model convergence across training rounds.
